Hakster CLI · Paid Pro

Install in your terminal

Install the CLI, then sign in with the HaksterAI account that has Pro access. The install does not change your account or plan.

Quick install · macOS / Linux
curl -fsSL https://haksterai.com/install.sh | bash
Install from source with npm
git clone --depth 1 https://github.com/Deko38code/haksterAi.git ~/.local/share/haksterai-cli
cd ~/.local/share/haksterai-cli/cli
npm install
npm link

Requires Node.js 22.12 or newer and Git. After installation, run hakster --help to see CLI commands. The install path must not already exist.

Why it stays cheap

Most of these bots don't call the expensive closed APIs. They run on open models through our own endpoint — DeepSeek above all — so a conversation costs us cents instead of dollars, and the catalog runs without a per-token meter attached to your account. Big-model names are still there when the job needs one; the default route is the cheap one, on purpose.
