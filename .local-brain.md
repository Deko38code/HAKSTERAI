# haksterAi Local Brain

## Project Architecture
- haksterAi is an AI-powered CLI for developers
- CLI entry: cli/index.js (Node.js)
- Proxy: claude-code-proxy/ (Python + Node.js)
- Memory: .hakster/memories/ and .hakster/memory/
- Skills: .hakster/skills/*.md

## Key Components
- `cli/index.js` — main CLI entry point
- `claude-code-proxy/` — proxy server (port 8084)
- `claude-code-proxy/shared_memory.py` — shared agent memory
- `claude-code-proxy/brain_recall.py` — active recall injection
- `claude-code-proxy/fast_brain_bridge.py` — brain aggregation
- `claude-code-proxy/cross_agent_teacher.py` — cross-agent teaching

## Common Tasks
- Brain rebuild: `python3 fast_brain_bridge.py`
- Recall test: `python3 brain_recall.py "query"`
- Inject test: `echo "query" | node brain_inject.js --stdin`
- PM2 daemon: `pm2 list | grep sonnet`

## Known Issues
- Port 8084 must be free before starting proxy
- Don't use port 8080 (CineVault conflict)
- shared_memory.py uses tabs, not spaces
